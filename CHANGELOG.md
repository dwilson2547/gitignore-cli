# Changelog

## [0.2.0]

- Added `--list` flag: prints all available template names to stdout (one per line) without opening the TUI.
- Added `--quiet <template>` flag: fetches and applies a template non-interactively; supports case-insensitive name matching.
- Added `--version` / `-v` flag.
- Added `--help` / `-h` flag with usage summary.
- Added `README.md` and `docs/headless-flags.md` with design and implementation notes.

## [0.1.0]

- Initial release: interactive gitignore generator with GitHub template list, 24 h cache, and create/append support.
